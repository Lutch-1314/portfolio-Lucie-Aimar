Projets

Trouve ton artisan

Dans le cadre de ma formation Développeur Web et Web Mobile, j'ai réalisé une application web de mise en relation entre particuliers et artisans de la région Auvergne-Rhône-Alpes. Ce projet m'a permis d'intervenir sur l'ensemble du cycle de développement, aussi bien côté front-end que back-end. J'ai conçu les maquettes avec Figma, développé l'interface utilisateur avec React, Bootstrap et Sass, puis créé une API sécurisée avec Node.js, Express et Sequelize, reliée à une base de données MySQL. L'application a été pensée selon une approche mobile first, avec une attention particulière portée à l'accessibilité (WCAG 2.1), à la conformité du code aux standards du W3C et à la cohérence de l'expérience utilisateur avec le site institutionnel de la Région Auvergne-Rhône-Alpes. Le projet a également été versionné avec Git et GitHub tout au long de son développement.

Technologies utilisées

  • Figma
  • React
  • Bootstrap
  • Sass
  • Node.js
  • Express
  • Sequelize
  • MySQL
  • Git / GitHub

API - Port de plaisance Russell

Dans le cadre de ma formation Développeur Web, j'ai conçu une API RESTful dédiée à la gestion d'un port de plaisance. Cette application permet de gérer les catways, les réservations et les utilisateurs via une interface d'administration sécurisée. Le projet inclut un système d'authentification par JWT, une gestion des rôles (administrateur et lecteur), une base de données MongoDB, ainsi qu'une documentation complète de l'API avec Swagger. L'application a été développée avec Node.js et Express, puis déployée sur Render afin de permettre son utilisation et sa démonstration.

Technologies utilisées

  • Node.js
  • Express
  • MongoDB & Mongoose
  • JWT Authentication
  • Swagger / OpenAPI
  • EJS
  • Postman
  • Git / GitHub
